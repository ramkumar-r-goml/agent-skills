# Glossary

Alphabetical. Each entry has the term, a one-sentence definition, where it appears in code, and the terms not to use as synonyms. Include project-specific meanings of common words, because those cause the worst confusion.

Build it from the term inventory you make while writing. Vale can enforce the result through a vocabulary file: see `references/docs-ci.md`.

```markdown
# Glossary

| Term | Meaning | In code | Do not call it |
|---|---|---|---|
| <term> | <one sentence> | `<identifier or path>` | <rejected synonyms> |
```
