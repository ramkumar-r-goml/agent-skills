# Tutorial

Purpose: a learner gains skill by completing a guided exercise that works every time. It is a lesson, so choose one path and teach by doing. Save options for how-to guides, and theory for explanation pages.

Rules:

- List prerequisites at the top and assume no other setup.
- Give small visible wins, with expected output after each step.
- Number only actions the user takes.
- Keep theory to a line, and link to the explanation.
- End with what they built and one or two next steps.
- Write it by doing it from nothing, noting each step and mistake, then trim. Test from a clean environment, since a tutorial that fails once loses the reader.

````markdown
# Tutorial: <build or learn X>

By the end you will have <concrete result>. It takes about <n> minutes.

## What you need

<Exact tools and versions.>

## Step 1: <outcome-named step>

<Action.>

```bash
<command>
```

You should see:

```text
<output>
```

## What you built

<Two sentences.>

## Next

<One or two links.>
````
